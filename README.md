# Tactimon Online

Tactimon Online is a non-commercial fan MMORPG prototype built around a persistent multiplayer world and grid-based tactical Pokémon battles.

## Local asset workflow

ROMs and extracted assets remain only on the user's machine.

Place supported ROMs in:

```text
local-assets/roms/
```

Extract raw compressed blocks:

```bash
python tools/asset-extractor/extract.py local-assets/roms/firered.gba --clean
```

Convert the world assets used by Tactimon:

```bash
python tools/asset-extractor/convert_world.py local-assets/roms/firered.gba
```

This generates trainer sprites, overworld/player/NPC sprite sheets and reconstructed tileset/metatile assets under `local-assets/extracted/<game>/assets/`.

Pokemon battle sprites are no longer generated by default because Tactimon plans to use the PMDCollab/Mystery Dungeon-style Pokémon sprite pipeline instead.

See `tools/asset-extractor/README.md` and `docs/ASSETS.md`.
