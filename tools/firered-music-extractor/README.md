# FireRed music extractor

The FireRed soundtrack is no longer synthesized by Tactimon code.

Normal use remains:

```bash
pnpm dev
```

When the required music is missing or was generated by the old renderer, the predev step:

1. finds the supported FireRed ROM under `local-assets/roms/`;
2. creates a local Python virtual environment under `local-assets/.tools/`;
3. installs the pinned `gba-audio-tools` revision `45e84ba8a5a47b22e56dac7e4e87b1ac605bcb19`;
4. extracts the selected FireRed MP2K/Sappy songs to `firered-music.pak`;
5. renders those songs with `gba-audio-tools`' C MP2K engine at 32,768 Hz;
6. copies the resulting runtime WAVs into the client assets.

The dependency is kept external instead of copying its GPL-3.0-or-later source into Tactimon.

Supported FireRed SHA-1:

```text
41cb23d8dccc8ebd7c649cd8fbb58eeace6e2fdc
```

Current tracks are 291 (Route 1), 297 (trainer/rival battle), 298 (wild battle), 300 (Pallet Town), 301 (Professor Oak's Lab), and 314 (Viridian/Pewter).

Generated files:

```text
local-assets/extracted/firered/music/firered-music.pak
local-assets/extracted/firered/music/runtime/*.wav
local-assets/extracted/firered/music/runtime/manifest.json
```

To prepare only the music:

```bash
pnpm music
```

The first run requires Python 3.10+, internet access to GitHub, and a working C compiler so the pinned renderer can be installed. Subsequent runs reuse the local tool environment.

Neither the ROM, the extracted `.pak`, nor the rendered commercial music files are committed.
