# Local assets

Everything in this directory is meant to stay on your own machine.

## Folders

- `roms/`: put your supported FireRed/Emerald `.gba` files here.
- `extracted/`: output generated by the Python ROM extractor.
- `spritecollab/`: optional local SpriteCollab checkout or locally prepared sprite assets.

Git ignores the contents of these folders.

## Example

```bash
python tools/asset-extractor/extract.py local-assets/roms/emerald.gba --clean
```

Output:

```text
local-assets/extracted/emerald/
  manifest.json
  lz77/
    002EC88C_0003584_14b7b4d1fd.bin
    ...
```

The manifest preserves ROM offsets and hashes so later game-specific import stages can turn raw blocks into named assets deterministically.
